# TeamSync 重点文件位置索引

本文档按功能模块列出 TeamSync 的重点文件位置，适合后续排查问题、扩展功能、定位接口和维护数据库脚本时使用。

## 根目录文件

| 路径 | 用途 |
| --- | --- |
| `doc/项目开发基线.md` | 开发基线、接口、表结构和改造优先级 |
| `doc/未来功能规划.md` | 后续功能扩展方向、实施顺序和验证建议 |
| `doc/重点文件位置索引.md` | 当前文件位置索引 |
| `doc/站内通知功能说明.md` | 站内通知中心功能、入口、接口和路由维护口径 |

| 路径 | 用途 |
| --- | --- |
| `TeamSync_web/src/router/index.js` | Router 实例 |

| `TeamSync_web/src/router/guards/afterEach.js` | 路由后置处理 |
| `TeamSync_web/src/router/core/RouteTransformer.js` | 菜单转路由 |
| `TeamSync_web/src/router/core/ComponentLoader.js` | 动态加载视图组件 |
| `TeamSync_web/src/router/modules/dashboard.js` | 仪表盘模块路由，包含 `/dashboard/calendar` 日历入口 |
| `TeamSync_web/src/router/modules/project.js` | 项目模块路由定义 |
| `TeamSync_web/src/router/modules/recurring-plan.js` | 周期计划兼容路由 |
| `TeamSync_web/src/router/modules/system.js` | 系统管理模块路由 |
| `TeamSync_web/src/router/modules/profile.js` | 个人中心和通知中心路由，包含 `/user/notifications` |

注意：当前 `TeamSync_web/.env` 默认 `VITE_ACCESS_MODE=frontend`，菜单主口径是前端 `router/modules`。实际路由入口和模块文件使用 `.js`，不要只改同名 `.ts`。原有路由 `.ts` 已备份到 `doc/router-ts-backup-20260608.tar` 后从 `src/router` 删除。切到 `backend` 模式时，菜单主口径变成后端 `MenuController` 的 `/api/v3/system/menus/simple`，而该接口当前只返回仪表盘、项目管理、周期计划兼容入口。修改菜单、路由、页面入口时要同时确认运行模式、后端菜单和前端路由注册路径。
