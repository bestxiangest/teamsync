# 管理看板统计数据库变更

## 变更结论

本阶段没有新增业务表，也没有新增业务字段。管理看板统计直接复用现有任务、项目成员、周期计划和周期计划执行实例表。

为降低按项目、成员、时间范围聚合时的扫描成本，已在数据库中创建 7 个辅助索引。

## 已执行 DDL

```sql
CREATE INDEX IF NOT EXISTS idx_pm_task_dashboard_project_due
    ON teamsync.pm_task (project_id, is_deleted, due_time);

CREATE INDEX IF NOT EXISTS idx_pm_task_dashboard_updated
    ON teamsync.pm_task (is_deleted, updated_at);

CREATE INDEX IF NOT EXISTS idx_pm_task_member_dashboard_user
    ON teamsync.pm_task_member (user_id, role, task_id);

CREATE INDEX IF NOT EXISTS idx_pm_task_member_dashboard_task
    ON teamsync.pm_task_member (task_id, role, user_id);

CREATE INDEX IF NOT EXISTS idx_pm_recurring_plan_dashboard_project
    ON teamsync.pm_recurring_plan (project_id, is_deleted, status, next_run_at);

CREATE INDEX IF NOT EXISTS idx_pm_recurring_occurrence_dashboard_plan_due
    ON teamsync.pm_recurring_plan_occurrence (plan_id, due_time, status);

CREATE INDEX IF NOT EXISTS idx_pm_recurring_occurrence_dashboard_start
    ON teamsync.pm_recurring_plan_occurrence (scheduled_start_at);
```

## 验证结果

已通过 `pg_indexes` 查询确认以下索引存在：

- `idx_pm_recurring_occurrence_dashboard_plan_due`
- `idx_pm_recurring_occurrence_dashboard_start`
- `idx_pm_recurring_plan_dashboard_project`
- `idx_pm_task_dashboard_project_due`
- `idx_pm_task_dashboard_updated`
- `idx_pm_task_member_dashboard_task`
- `idx_pm_task_member_dashboard_user`

## 统计字段来源

- 任务完成、逾期、即将到期：`pm_task.status`、`pm_task.stage_id`、`pm_task.due_time`、`pm_task.updated_at`
- 项目健康：`pm_project.progress`、任务完成率、逾期任务数、待办任务数
- 成员负载：`pm_task_member.role = 'EXECUTOR'`、任务优先级、任务截止时间、周期计划负责人
- 周期计划执行率：`pm_recurring_plan`、`pm_recurring_plan_assignee`、`pm_recurring_plan_occurrence.status`
